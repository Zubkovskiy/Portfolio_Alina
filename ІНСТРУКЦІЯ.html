1 Як відкрити сайт локально

Просто знайди файл index.html у папці сайту і відкрий його в браузері подвійним кліком. Більше нічого не потрібно — сайт не вимагає сервера.

💡 Для зручної розробки рекомендуємо VS Code + розширення Live Server — воно автоматично оновлює сайт при збереженні файлів.

2 Як додавати роботи в портфоліо

Крок 1 — Додай файли в папку

Скопіюй своє фото або відео в папку:

img/portfolio/

Файли можуть мати будь-яку назву. Підтримуються: .jpg.png.webp.mp4.mov

Крок 2 — Відкрий main.js і знайди масив PROJECTS

Відкрий файл main.js у будь-якому текстовому редакторі (наприклад Notepad++ або VS Code). Знайди блок:

const PROJECTS = [
  // ── AI-фото ──────────────────
  {
    id: 'fashion',
    ...
  },
  ...

Кожен об'єкт у масиві — це один проєкт на сторінці.

Крок 3 — Додай новий проєкт

Скопіюй шаблон нижче і встав його в потрібний розділ:

{
  id: 'my-project',           // унікальна назва латиницею
  cat: 'photo',               // категорія: photo | video | youtube | ad
  tag: 'AI-фото · Beauty',    // текст тегу на картці
  tagColor: '',               // колір тегу: '' | 'yellow' | 'pink'
  title: 'Назва проєкту',     // назва в лайтбоксі
  coverPos: 'top',            // вирівнювання обкладинки (див. розділ 3)
  items: [
    { type: 'img', src: 'img/portfolio/моє-фото.jpg' },
    { type: 'img', src: 'img/portfolio/ще-одне.jpg' },
  ]
},
💡 Якщо хочеш додати відео — зміни type: 'img' на type: 'video'

Додаткові параметри картки

  • wide: true — картка займає 2 колонки (широка)
  • tall: true — картка займає 2 рядки (висока)

Як згрупувати кілька фото в один проєкт

Просто додай кілька файлів в масив items:

items: [
  { type: 'img', src: 'img/portfolio/фото-1.jpg' },
  { type: 'img', src: 'img/portfolio/фото-2.jpg' },
  { type: 'img', src: 'img/portfolio/фото-3.jpg' },
  { type: 'video', src: 'img/portfolio/відео.mp4' },
]

На картці автоматично з'явиться значок з лічильником. При кліку відкривається галерея з навігацією.

3 Як вирівнювати фото на картках

Параметр coverPos контролює яка частина фото видна в картці-обкладинці. Фото обрізається, тому важливо показати потрібну частину.

Доступні значення

  • 'top' — показує верхню частину (обличчя, голова) ← для портретів людей
  • 'center' — показує центр (default) ← для горизонтальних і дизайн-файлів
  • 'bottom' — показує нижню частину
  • '50% 30%' — точні координати: % горизонтально, % вертикально

Приклад тонкого налаштування

coverPos: '50% 20%'  // центр по горизонталі, 20% від верху
💡 Якщо на картці відображається не та частина — просто зміни значення coverPos і збережи файл.

4 Налаштування форми → Telegram

Крок 1 — Створи свого бота

  1. Відкрий Telegram і знайди @BotFather
  2. Напиши команду /newbot
  3. Дай боту ім'я (наприклад: MyPortfolio Bot)
  4. Дай боту username що закінчується на _bot (наприклад: myportfolio_bot)
  5. BotFather видасть тобі TOKEN — збережи його

Крок 2 — Отримай свій Chat ID

  1. Напиши будь-яке повідомлення своєму боту в Telegram
  2. Відкрий в браузері це посилання (підстав свій токен):
https://api.telegram.org/botТВІЙ_ТОКЕН/getUpdates

У відповіді знайди "chat":{"id": 123456789} — це і є твій Chat ID.

Крок 3 — Встав дані в main.js

Відкрий файл main.js, знайди рядки:

const TG_TOKEN   = '8373382072:AAGu...';
const TG_CHAT_ID = '443233079';

Заміни значення на свої:

const TG_TOKEN   = 'ТВІЙ_ТОКЕН_ВІД_BOTFATHER';
const TG_CHAT_ID = 'ТВІЙ_CHAT_ID';
⚠️ Токен бота — це секретні дані. Не ділись ним з іншими людьми і не публікуй у відкритих постах.

5 Розміщення на GitHub Pages (безкоштовно)

Що таке GitHub Pages?

Це безкоштовний хостинг від GitHub для статичних сайтів. Ідеально підходить для портфоліо. Адреса буде виглядати так: https://твій-нікнейм.github.io/назва-репозиторію/

Крок 1 — Зареєструйся на GitHub

Перейди на github.com і створи безкоштовний акаунт.

Крок 2 — Створи репозиторій

  1. Натисни кнопку New repository
  2. Назви його, наприклад: portfolio
  3. Постав галочку Public
  4. Натисни Create repository

Крок 3 — Завантаж файли

На сторінці репозиторію натисни uploading an existing file і перетягни всі файли сайту (index.html, style.css, main.js, папку img). Натисни Commit changes.

💡 Або використай GitHub Desktop — безкоштовну програму для зручної роботи з Git без командного рядка: desktop.github.com

Крок 4 — Увімкни GitHub Pages

  1. Перейди в Settings репозиторію
  2. В лівому меню знайди Pages
  3. В розділі Source вибери Deploy from a branch
  4. Гілка: main, папка: / (root)
  5. Натисни Save

Через 1-2 хвилини сайт буде доступний за посиланням яке з'явиться на тій же сторінці.

⚠️ Відео-файли розміром >50 МБ можуть не завантажитись на GitHub Pages. Для важких відео краще використовувати платний хостинг або YouTube/Vimeo embed.

6 Платний хостинг і власний домен

Навіщо платний хостинг?

  • Власний домен: linacreatica.com замість github.io
  • Підтримка великих відео-файлів
  • Email на власному домені: lina@linacreatica.com
  • Більша швидкість і надійність

Де купити домен

Рекомендовані реєстратори:

  • Namecheap (namecheap.com) — дешевий, зручний
  • NIC.UA (nic.ua) — українські домени .ua, .com.ua
  • Hostinger (hostinger.ua) — домен + хостинг разом

Домен зон .com, .site, .studio коштує від $8-15/рік.

Де купити хостинг

Для простого статичного сайту достатньо найдешевшого тарифу:

  • Hostinger — від ≈$2-3/міс, є українська підтримка
  • Netlify (netlify.com) — безкоштовно для статичних сайтів, підтримує великі файли, власний домен
  • Vercel (vercel.com) — безкоштовно, дуже швидкий
💡 Рекомендація: Netlify — безкоштовний, підтримує файли до 100 МБ, легко налаштовується. Купуєш домен окремо і прив'язуєш до Netlify безкоштовно.

Як завантажити сайт на Netlify

  1. Зареєструйся на netlify.com
  2. Натисни Add new site → Deploy manually
  3. Перетягни папку сайту в браузер
  4. Сайт одразу доступний за автоматичною адресою
  5. В налаштуваннях сайту: Domain settings → Add custom domain — вкажи свій домен
